# Tidyline — Start Here

1. Open `README-FINAL.md`.
2. Keep `index.html` as the approved customer page.
3. Run the existing Supabase migrations in your project, then run `supabase/migrations/011_admin_staff_integration.sql`.
4. Configure `config.js` with your Supabase project values if deploying to another project.
5. Create an Admin Auth account and use `admin.html`.
6. Add staff in Admin, create their Auth accounts, link `auth_user_id`, then use `staff.html`.
